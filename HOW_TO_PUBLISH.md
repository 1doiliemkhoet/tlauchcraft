# GitHub sync

The research repository is already initialized at https://github.com/1doiliemkhoet/tlauchcraft (`main`).

To clone locally:

```powershell
git clone https://github.com/1doiliemkhoet/tlauchcraft.git
cd tlauchcraft
```

Further findings should be committed as text documents, contracts and test results only. Never push third-party EXE/JAR binaries, Minecraft game assets, credentials, access tokens, locally generated worlds, or proprietary launcher resources.

The repo contains research, **not a released or tested launcher**. See ROADMAP.md before implementation.
